## ⭐ Featured

🔖 **[third-street-bookmarks-macapp](https://github.com/mayanksagar26/third-street-bookmarks-macapp)** — *Native macOS bookmark manager with AI chat, podcast digests and local categorisation.* One searchable library for X (Twitter) bookmarks, Hacker News, YouTube playlists, Instagram saves and any link. Chat with your bookmarks (answers cite what they found), turn any slice into an audio digest, and let a local model (Laya) sort them by your own labels. A Tauri 2 shell around a supervised Node sidecar, shipped as a real `.app` / `.dmg` (v1.2.0, Apple Silicon). Everything stays in `~/.tsb`; the AI runs on your Claude Code or Codex CLI, with the agent sandboxed read-only. Tauri · Rust · React · Node · SQLite.

🌐 **[third-street-bookmarks](https://github.com/mayanksagar26/third-street-bookmarks)** — The same library as a browser app on `localhost`, sharing the same data folder as the Mac app. Node + React. Built on Andrew Farah's [Field Theory](https://github.com/afar1/fieldtheory-cli) CLI for X bookmarks.

🧹 **[menlo](https://github.com/mayanksagar26/menlo)** — A calmer place for your files. A native macOS file organiser that clears Downloads and Desktop by rules you write in plain words — *"anything with the word lease goes here"*. Previews every move, catches duplicates, and every run can be undone. Works with no AI at all. Tauri + Rust + React.

🎬 **[vid-bid](https://github.com/mayanksagar26/vid-bid)** — Swap the product inside a video using open models only (SAM 2, CLIP, YOLO-World, Wan 2.1 VACE). Free, no paid APIs, includes a CLI and a Colab GPU notebook. Python + FastAPI.
