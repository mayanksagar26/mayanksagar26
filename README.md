## Featured: local-first AI apps

🖥️ **[third-street-bookmarks-macapp](https://github.com/mayanksagar26/third-street-bookmarks-macapp)** — *Latest: v1.2.0, native macOS (Apple Silicon).* A private, local-first bookmark manager that turns X (Twitter), Hacker News, YouTube (incl. Watch Later) and Instagram saves plus any link into one searchable library, with AI chat that cites its sources, podcast digests and auto-categorising. Tauri 2 + Rust shell around a supervised Node sidecar, packaged as a real `.app` / `.dmg`. No API key, no account, nothing uploaded — the AI runs on the Claude Code or Codex CLI you already have. Hardened by design: loopback-only, per-launch token, read-only agent sandbox.

🔖 **[third-street-bookmarks](https://github.com/mayanksagar26/third-street-bookmarks)** — The same library as a Node + React app on `localhost`. Both builds share one data folder.

🧹 **[menlo](https://github.com/mayanksagar26/menlo)** — A calmer place for your files. A native macOS app that tidies Downloads and Desktop by rules written in plain words, previews every move, catches duplicates, and makes every run undoable. Works with no AI at all. Tauri + Rust + React.

🎬 **[vid-bid](https://github.com/mayanksagar26/vid-bid)** — Swap the product inside a video, free and open source end to end (SAM 2 + CLIP + YOLO-World, or Wan 2.1 VACE for realistic re-rendering). CLI plus a free Colab GPU notebook. Python + FastAPI.

🎙️ **[voice-claw-android](https://github.com/mayanksagar26/voice-claw-android)** — TJ, a voice companion for self-hosted OpenClaw agents: tap, speak, hear a reply, all on-device STT/TTS. Kotlin + Jetpack Compose.
