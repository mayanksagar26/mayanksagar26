## Featured: Third Street Bookmarks

A local-first **AI bookmark manager** for X, Hacker News, YouTube, Instagram and any link, in one searchable, categorised library you can chat with and listen to.

| | Repo | What you get |
|---|---|---|
| 🖥️ **Mac app** | **[third-street-bookmarks-macapp](https://github.com/mayanksagar26/third-street-bookmarks-macapp)** | Native macOS `.app` / `.dmg` (v1.2.0, Apple Silicon). Tauri 2 shell around a supervised Node sidecar. No terminal, no localhost tab. |
| 🌐 **Web / localhost** | **[third-street-bookmarks](https://github.com/mayanksagar26/third-street-bookmarks)** | Same library served from a small local Node + React server. Shares `~/.tsb` with the Mac app. |

Chat with citations over your own bookmarks, podcast-style digests with voice, auto-categorising (regex, Claude, Codex, or a model trained on your labels), analytics and colour-label triage. The AI runs on the coding CLI you already have, so there is no API key, no upload and no account.

### More local-first apps

🧹 **[menlo](https://github.com/mayanksagar26/menlo)** — A calmer place for your files. A native macOS app that clears Downloads and Desktop into the folders you choose, by rules you write in plain words — *"anything with the word lease goes here"*. 🎬 **[vid-bid](https://github.com/mayanksagar26/vid-bid)** — Swap the product inside a video: upload a clip or paste a YouTube link, pick a detected object, give it a photo of your product, and get the same video back with your product in its place. Free and open source end to end, with no paid APIs, keys or accounts. A fast engine wraps the product onto the tracked shape (SAM 2 + CLIP + YOLO-World), and a realistic engine re-renders the region with the open Wan 2.1 VACE model on your own machine. Includes a CLI and a free Colab GPU notebook. Python + FastAPI.
