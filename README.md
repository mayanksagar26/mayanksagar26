## Featured: Third Street Bookmarks

> **A private, local-first AI bookmark manager for macOS.** Search, chat with and listen to everything you save from **X (Twitter), Hacker News, YouTube, Instagram** and any link — in one categorised library. The AI runs on the **Claude Code or Codex CLI** you already have: **no API key, no account, nothing uploaded.**

🖥️ **[third-street-bookmarks-macapp](https://github.com/mayanksagar26/third-street-bookmarks-macapp)** — the native **macOS app** (`.app` / `.dmg`). Tauri 2 + Rust shell supervising a Node sidecar, React UI, SQLite state. Shipped at **v1.2.0** (Apple Silicon).
- 💬 Chat with your bookmarks · 🎙️ AI podcast digests · 🗂️ auto-categorising (keyword rules, Claude, Codex, or [Laya](https://github.com/NandhaKishorM/laya) trained on your own labels)
- 📥 Hacker News browser, YouTube playlists & Takeout, Instagram export import, X sync via Field Theory
- 🔒 Security-first: loopback-only, per-launch bearer token, Origin/Host checks, read-only sandboxed agents, `WebFetch` denied

🔖 **[third-street-bookmarks](https://github.com/mayanksagar26/third-street-bookmarks)** — the same app as a browser build on `localhost`. Both share `~/.tsb`, so they open the same collection.

*Keywords: macOS app, Tauri, Rust, bookmark manager, X/Twitter bookmarks, Hacker News, YouTube Watch Later, Instagram saved posts, local-first, privacy, Claude Code, Codex CLI, AI second brain.*
