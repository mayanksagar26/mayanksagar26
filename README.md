## ⭐ Featured: Third Street Bookmarks for macOS

<a href="https://github.com/mayanksagar26/third-street-bookmarks-macapp"><img src="https://raw.githubusercontent.com/mayanksagar26/third-street-bookmarks-macapp/main/docs/screenshots/02-feed.png" alt="Third Street Bookmarks: one feed for X, Hacker News, YouTube and Instagram bookmarks" width="100%"></a>

**[third-street-bookmarks-macapp](https://github.com/mayanksagar26/third-street-bookmarks-macapp)** is an open-source, local-first bookmark manager and read-later app for Mac. It pulls **X/Twitter bookmarks, Hacker News, YouTube playlists (Watch Later too), Instagram saved posts and any URL** into one searchable, categorised library.

- 💬 **Chat with your bookmarks.** Answers cite the saves they came from, and run on your local Claude Code or Codex CLI.
- 🎧 **Bookmark podcasts.** Turn any slice of your library into an audio digest.
- 🧠 **Offline categorising.** A small model trained on your own labels ([Laya](https://github.com/NandhaKishorM/laya)), about ten times faster than an LLM call.
- 🔒 **Built like a real service, even on localhost.** Loopback-only, per-launch token, DNS-rebinding checks, and agents sandboxed read-only against prompt injection.
- 🖥️ **Native app.** Tauri 2 + Rust supervisor + Node sidecar. **v1.2.0**, Apple Silicon `.dmg`.

[**Download for macOS →**](https://github.com/mayanksagar26/third-street-bookmarks-macapp/releases/latest) · Prefer the browser? [third-street-bookmarks](https://github.com/mayanksagar26/third-street-bookmarks) runs on `localhost` and shares the same `~/.tsb` library.

**Recently shipped:** two servers on one library no longer lose each other's writes, and favourites keep their date when refiled. **Next:** an [ACP](https://agentclientprotocol.com) agent harness with persistent chat sessions, then any agent (Goose, open-weight models) as a config row.
